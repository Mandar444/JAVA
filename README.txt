BACKUP AND PRIVACY
Progress is stored in this browser profile's IndexedDB on your machine.
Chrome, Edge and Codex's in-app browser have separate storage.
Changing from 127.0.0.1 to localhost, or changing the port, changes storage.
Export progress JSON regularly using the sidebar or Settings & backups.
Clearing browser data can erase progress; exported backups let you restore it.
Version 2 exports include preparation notes, mocks, applications and preferences.
Version 1 backups are still accepted. Import previews deduplicate event IDs and
ask how to resolve conflicting copies. Old backups do not erase new career data.
No application is submitted by this tracker. External links open only on click.
